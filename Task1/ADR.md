# ADR-1: MVP системы отслеживания свинофермы
# Статус: согласовано

## 1. Контекст

Компании Агро Тех нужно запустить ИИ-платформу для отслеживания свиноферм с помощью ИИ-агентов. В дальнейшем платформу можно предлагать клиентам сегмента B2B.

Появляется необходимость раннего выявления заболеваний, стресса и проблем благополучия животных для минимизации потерь. Стоит повысить эффективность в сфере животноводства и по максимуму автоматизировать процессы, связанные с кормлением, безопасностью и мониторингом поголовья скота.

**Ключевые бизнес-проблемы и цели:**

- **Раннее выявление рисков:** Традиционные методы мониторинга (визуальный осмотр, ручной учет) не позволяют оперативно обнаруживать заболевания, признаки стресса (агрессия, апатия), нарушения благополучия (перегрев, травмы) или отклонения в поведении. Это приводит к потерям поголовья в пиковые периоды. ИИ-платформа должна анализировать видео и сенсорные данные в реальном времени для прогнозирования рисков.
    
- **Оптимизация процессов:** Автоматизация кормления (рекомендации по рациону на основе веса и активности), контроля безопасности (детекция вторжений, пожаров) и мониторинга поголовья (счет животных, группировка по состоянию). Цель — снижение затрат за счет минимизации ручного труда и потерь корма/продукции.

**Техническая основа:**

- **Источники данных:** Камеры видеонаблюдения (RTSP/HLS-потоки), IoT-сенсоры (температура, влажность, CO2, RFID-метки), исторические данные о кормлении.
    
- **ИИ-компоненты:** Обнаружение объектов в изображении (YOLO/Detectron для детекции животных), ML-модели (LSTM для анализа поведения, anomaly detection для болезней), edge-вычисления на фермах для снижения latency.
    
- **Масштабируемость:** MVP для 1–2 ферм (до 5000 голов), с возможностью cloud-расширения (Yandex Cloud).

## 3. Решение

### Описание

Для реализации MVP создаем отдельную систему управления скотом (Сattle Management System, CMS), развернутую в облаке (Yandex Cloud).                                                                                                                                     
**Есть два варианта решений:**

1. **Интеграция с "Цифровой платформой":** CMS как микросервис внутри существующей экосистемы (shared auth, данные в общем хранилище). Подходит для внутренних ферм "Агро Тех" — быстрое внедрение, единый UI.
    
2. **Полностью независимая SaaS-система:** Стандалон с multi-tenancy (изоляция данных по фермам/клиентам через RBAC). Идеально для B2B-продаж:

- Клиенты самостоятельно регистрируют аккаунт и добавляют фермы в веб-портале (self-service онбординг: вводят данные фермы — ID, локация, количество голов, API-ключи для edge-агентов).
    
- Автоматическое создание изолированного tenant'а с дашбордом, алертами и биллингом.
    
- Подписка по модели pay-per-farm/head (например, 500 ₽/мес за ферму + 1 ₽/голова).
    

  Нет зависимости от "Цифровой платформы" — полная автономия для быстрого развертывания у любого клиента.

В рамках нашей работы первый вариант предпочтителен для MVP — ускоренное время разработки, сохраняется возможность для масштабирования в SaaS-платформу.

## 4. Риски и компромиссы

## Риски

- **Технические:**  
    Низкая точность ИИ на noisy данных (грязь, плохое освещение) — риск ложных срабатываний.
    
- **Операционные:**  
    Зависимость от интернета на удаленных фермах.
    
- **Бизнес:**  
    Медленный adoption B2B (нужен proof-of-concept).
    
- **Масштаб:**  
    Cloud-расходы при росте
