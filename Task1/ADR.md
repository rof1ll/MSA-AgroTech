# ADR-1: Создание системы отслеживания свинофермы
# Статус: активно

## 1. Контекст

В современном бизнесе стоит задача создания системы для отслеживания свиноферм с помощью ИИ-агентов. Необходимость раннего выявления заболеваний, стресса и проблем благополучия животных для минимизации потерь. Стоит повысить эффективность в сфере животноводства и по максимуму автоматизировать процессы, связанные с кормлением, безопасностью и мониторингом поголовья скота.

## 3. Решение

### Описание

Для решения данной задачи решаем создать отдельную систему управления скотом. Есть два варианта решений, с интеграцией с существующими компонентами системы "Цифровая платформа" и без неё, как отдельная независимая система. Второе решение подходит для дальнейшей продажи как SaaS-решение.
